# 📝 Todo List

Un site web simple de gestion de tâches.

## ✨ Fonctionnalités prévues

* Ajouter une tâche
* Afficher la liste des tâches
* Consulter les détails d'une tâche
* Marquer une tâche comme terminée
* Modifier une tâche
* Supprimer une tâche
* Filtrer les tâches selon leur état
* Afficher un état vide lorsqu'aucune tâche n'est présente

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
